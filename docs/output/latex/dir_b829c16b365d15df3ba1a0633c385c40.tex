The package provides two model variants\+:
\begin{DoxyItemize}
\item {\ttfamily urdf/g1\+\_\+23dof.\+urdf} -\/ G1 with 23 degrees of freedom (fixed waist)
\item {\ttfamily urdf/g1\+\_\+29dof.\+urdf} -\/ G1 with 29 degrees of freedom (adding waist and wrist mobility)
\end{DoxyItemize}
