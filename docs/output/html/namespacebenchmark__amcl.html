benchmark_amcl.generate_launch_description ( )

Generates the launch description for the AMCL benchmark.

Configures and launches the nodes required to simulate the G1 robot in Gazebo, start the Nav2 stack with AMCL, insert any dynamic obstacles, and record error metrics via the evaluator node.

Returns
A LaunchDescription object containing all configured processes and nodes.
